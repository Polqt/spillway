# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities through GitHub's private vulnerability reporting feature. Open the repository's **Security** tab and select **Report a vulnerability** so the report is visible only to the maintainers.

Do not include real provider keys, Spillway API keys, or other credentials in a report. Use fake keys and redact secrets from logs, configuration, and reproduction steps.

## Supported versions

Security fixes are provided for the latest minor release in the v1 series. Upgrade to the latest v1 release before reporting an issue when possible.
