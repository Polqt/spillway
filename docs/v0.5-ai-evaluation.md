# Stage 2 local classifier evaluation

## Decision

The optional local classifier remains opt-in and disabled unless explicitly configured.
This paired run exercised the classifier's unavailable-service fallback, not a working AI classifier, and cannot support a promotion decision.
The mock answers make cost savings undefined, and no blinded human ratings were collected.

The paired prompt-cluster bootstrap sampled the six prompt IDs with replacement, retaining all repeats and arms for each sampled prompt.
For 10,000 replicates with seed `20261016`, the p95 latency-regression interval against current auto was 0% to 0% for rules and 0% to 50% for the unavailable-classifier arm.
The classifier fallback interval exceeds the 5% upper-bound gate, but reflects only a local connection-refusal fallback path and millisecond mock timings.
The following Python 3 standard-library snippet reproduces both intervals from the local `metrics.json` artifact.
It uses the same nearest-rank percentile as the evaluation harness and percentile bounds at the 2.5th and 97.5th bootstrap percentiles.

```python
import json, math, random
from collections import defaultdict

report = json.load(open(".scratch/v0.5-smart-routing/evaluation-stage2-offline/run/metrics.json", encoding="utf-8"))
trials = defaultdict(lambda: defaultdict(list))
for row in report["trials"]:
    trials[row["prompt_id"]][row["arm"]].append(row["latency_ms"])
prompts = list(trials)
rng = random.Random(20261016)
results = {arm: [] for arm in ("rules", "classifier-unavailable")}

def p95(values):
    return sorted(values)[math.ceil(.95 * len(values)) - 1]

for _ in range(10_000):
    sample = {arm: [] for arm in ("current-auto", *results)}
    for _ in prompts:
        prompt = rng.choice(prompts)
        for arm in sample:
            sample[arm].extend(trials[prompt][arm])
    baseline = p95(sample["current-auto"])
    for arm in results:
        results[arm].append(p95(sample[arm]) / baseline - 1)

for arm, values in results.items():
    values.sort()
    low, high = values[math.floor(.025 * len(values))], values[math.ceil(.975 * len(values)) - 1]
    print(arm, f"{100 * low:.1f}% to {100 * high:.1f}%")
```

## Reproduction

Start the first two arms with `examples/config.eval.yaml` and `examples/config.eval.rules.yaml`.
For the third arm, use the same mock tier and rules config with `server.listen: 127.0.0.1:8082`, `providers.ollama.base_url: http://127.0.0.1:11435/v1`, and `router.classifier.model: ollama/llama3.2:3b`.
Leave port 11435 unused to reproduce the unavailable-service fallback measured here.
Then run:

```powershell
$env:SPILLWAY_EVAL_KEY = "sk-test-spillway-evaluation"
go run ./apps/spillway eval -dataset examples/evaluation-prompts.v1.json -arms current-auto=auto@http://127.0.0.1:8080,rules=auto@http://127.0.0.1:8081,classifier-unavailable=auto@http://127.0.0.1:8082 -repeats 30 -seed 20261016 -prices examples/evaluation-prices.mock.json -api-key-env SPILLWAY_EVAL_KEY -out .scratch/v0.5-smart-routing/evaluation-stage2-offline/run
Remove-Item Env:\SPILLWAY_EVAL_KEY
```

A promotion study still requires a working configured local model, identical priced candidate sets, representative prompts and at least two independent blinded raters, following [the evaluation protocol](v0.5-evaluation.md).
