# v1.0.0 Model and Tier CLI

Status: complete; shipped in v1.0.0; approved by the product owner on 2026-10-21
Target: replacement v1.0.0 release.

## Goal

Let users inspect configured models and tiers and replace an outdated model reference from Spillway commands.
Give Windows users a direct command for running the downloaded binary before adding it to `PATH`.

## Scope

- Add `spillway model list`, with tier and provider filters, zero-spend status and declared prices.
- Add `spillway tier list`, with spending permission, model count and `router.auto` order.
- Add `spillway model replace <old-model> <new-model>`, replacing exact references in tiers, model declarations, pricing and classifier configuration.
- Preserve config formatting, preview the change, save a backup and atomically write the updated file.
- Document `model`, `tier` and portable Windows executable commands.
- Replace the existing v1.0.0 release tag and assets only after release checks pass.

## Acceptance

- `spillway model --help` and `spillway tier --help` list their subcommands.
- List commands read the selected config and never print provider or local keys.
- Replacement rejects invalid references, missing source references and collisions, and reports the backup path after writing.
- `CGO_ENABLED=0 go build ./...` succeeds.
- Release CI passes before publishing the replacement v1.0.0 assets.

## Out of scope

- Provider account rotation or key pooling.
- Automatically discovering whether a provider currently offers a free quota.
- Removing or changing API keys, providers or tiers.
- A new stable version number.
